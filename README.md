# Make-Ondai-Geppo (ホール業務月報生成ツール)

日報が記録された Excel ファイルを読み込み、Gemini API を使用して自動的に要約し、編集・プレビューしながら美しい PDF 形式の月報を出力できるデスクトップアプリケーションです。

---

## 主な機能

* **デスクトップアプリ (GUI) 完結**: インストーラーから起動してすぐに利用できます。
* **キャンパス自動判別**: エクセルファイル名（例: `【YYYY年MM月】ホール業務日報_池袋キャンパス.xlsx`）から、「池袋キャンパス」または「中目黒キャンパス」を自動判別します。
* **AI による自動要約**: エクセル内の全日付シートから勤務データ・催事データ・報告事項を自動抽出し、Gemini API（推奨: `gemini-3.5-flash`）を使って月報用 Markdown テキストを生成します。
* **リアルタイム編集 & プレビュー**: 
  * 左側のエディターで生成された Markdown を直接編集できます。
  * 右側のプレビューエリアで、印刷時の A4 PDF 仕上がりイメージをリアルタイムに確認できます。
  * スライダーで余白（Padding）を自由に調整できます。
* **履歴管理**: 過去に生成した月報データは自動的に保存され、いつでも再編集やPDFの再出力が可能です。

## 導入手順（一般ユーザー向け）

### 1. アプリのダウンロードとインストール
1. 本リポジトリの [Releases](https://github.com/watatatata810/Make-Ondai-Geppo-Script/releases) ページから、最新のインストーラー（`Make-Ondai-Geppo.Setup.X.X.X.exe`）をダウンロードします。
2. ダウンロードしたファイルを実行してインストールします。
   > **⚠️ インストール時の注意 (Windows SmartScreen 警告)**
   > 本アプリは社内・特定関係者向けの配布ツールであるため、有償のデジタル署名を行っておりません。
   > 実行時に「Windows によって PC が保護されました」という青い警告画面が表示されますが、**「詳細情報」をクリックし、出現した「実行」ボタンを押す**ことで安全にインストールを進められます。

### 2. 初期設定（Gemini API キーの設定）
1. アプリを起動すると、API キーの入力画面が表示されます。
2. [Google AI Studio (API keys)](https://aistudio.google.com/api-keys) から取得したご自身の API キーを入力し、「SAVE API KEY」をクリックします。無料枠で十分使用可能です。
3. キーの検証が完了すると、メイン画面へ移行します（キーはOSの資格情報保護（Windowsの場合DPAPI）で暗号化してローカルに保存されるため、2回目以降の入力は不要です）。

## 基本的な使い方

### STEP 1: ファイルの読み込みとAI生成
1. 画面上のドラッグ＆ドロップエリアに、日報データが含まれる Excel ファイル（`.xlsx`）をドロップするか、「SELECT EXCEL FILE」から選択します。
2. モデル選択プルダウンで、使用する Gemini モデル（通常は `gemini-3.5-flash` 推奨）を選択します。
3. 必要に応じて「プロンプト確認・編集」から AI への要約指示文（プロンプト）を調整します。
4. 「月報生成」をクリックして生成を開始します（生成には 2〜4 分程度かかる場合があります）。

### STEP 2: 編集とPDFの出力
1. 生成が完了すると、スプリット（分割）画面が開きます。
2. **左ペイン（エディター）**: AI が生成した月報の文章を直接編集・修正します。
3. **右ペイン（プレビュー）**: PDFの仕上がりイメージを確認します。改ページなしの1ページに表示されます。
4. **余白調整**: 上部スライダーを動かすことで、印刷時の余白サイズ（ピクセル）を自由に調整できます。
5. 内容が確定したら、「PDF出力」ボタンをクリックして PDF ファイルを任意の場所に保存します。

## 開発者向け（ソースコードからの実行・ビルド）

本アプリは Electron + React (Vite) で構築されています。ソースコードからデバッグやビルドを行う場合は以下の手順に従ってください。

### 前提条件
* Node.js (v18 以上推奨)

### 開発環境の起動
依存パッケージをインストールし、React と Electron を同時にホットリロードモードで起動します。
```bash
npm install
npm run dev
```

### インストーラーのパッケージング
Windows 向けのスタンドアロンインストーラー（`.exe`）をビルドします。
```bash
npm run build
```
ビルド完了後、`release/` ディレクトリに `Make-Ondai-Geppo Setup X.X.X.exe` が生成されます。
